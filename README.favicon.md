# Favicon

The portfolio favicon uses a compact architecture/network motif designed to remain legible at browser-tab sizes. The three connected nodes use ArchiMate-inspired colors (yellow, green and blue) on the site's dark background and represent business, application/integration and technology viewpoints connected through a single architecture.

The source asset is `site/assets/favicon.svg`. The Pages build injects the correct relative favicon link into both the Russian root page and the English `/en/` page.
